# Task 2: Power BI Executive Dashboard

## Objective
Transform Superstore sales records into an executive dashboard to analyze sales, profit, monthly trends, regional performance, and product profitability.

## Tools
- Microsoft Power BI Desktop
- Power Query
- DAX

## Deliverables
- Executive Dashboard PDF report
- Power BI data model starter files
- DAX measures
- Dashboard setup guide

## Key Metrics
- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Year-over-Year Sales Growth

## Dashboard Visuals
- KPI scorecards
- Monthly sales trend
- Regional performance
- Category and sub-category profitability
- Discount sensitivity analysis

**Note:** The PDF is a static report. The interactive `.pbix` dashboard must be assembled and saved using Power BI Desktop.
